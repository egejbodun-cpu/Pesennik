# Песенник Ширы и Эгея

Откройте index.html в браузере.

Редактируйте песни в songs.js. Куплеты verses содержат строки текста. Аккорд записывается в квадратных скобках прямо перед символом, над которым он должен отображаться:

[C]Идёт отважный [F]воин,
Мо[C]гучий меч не[Dm]сёт,

Пробелы для выравнивания не нужны. При переносе слова аккорд остаётся с нужным символом. Аккорд в самом конце строки отображается после текста; перенесите его перед нужной буквой, если необходимо.

Обложка: cover.jpg. Аудиозаписи: папка audio. Транспонирование меняет только аккорды.

Для GitHub Pages загрузите содержимое site в репозиторий и включите публикацию из корня.

## Цвет отдельных реплик
Внутри строки можно выделить любой фрагмент:
"[color=#e9a1be][C]Я и красавец, и атлет![/color]"
"[color=#e9a1be]Стерва![/color] [color=#e8ad78]Тюфяк![/color] Змея! Козёл!"

После color= укажите цвет в формате #RRGGBB. Тег [/color] возвращает обычный цвет. Оформление действует только внутри одной строки. Аккорды сохраняют свой отдельный цвет. Для всего куплета добавьте теги в каждую строку. Выбирайте цвета, читаемые на тёмном и светлом фоне.

## Автоматические цвета персонажей
Используйте [color=pink]текст[/color] для розового персонажа и [color=orange]текст[/color] для оранжевого. Эти цвета автоматически меняют оттенок вместе с темой. Например:
"[color=pink][C]Я и красавец, и атлет![/color]"
"[color=pink]Стерва![/color] [color=orange]Тюфяк![/color]"
Оттенки можно изменить в конце style.css: --character-pink и --character-orange.
